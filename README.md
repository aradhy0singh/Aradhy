# Aradhy AI Video Generator

A public, self-hosted AI video generator based on [Agnes Video Generator](https://github.com/lcy362/agnes-video-generator) by [lcy362](https://github.com/lcy362).

Agnes creates multi-scene videos from text, with narration, subtitles, and a digital anchor. It is an open-source project released under the MIT License.

## Run the app

The application source and its up-to-date setup instructions are maintained in the upstream repository. Clone it and follow its README to install and launch the app:

```bash
git clone https://github.com/lcy362/agnes-video-generator.git
cd agnes-video-generator
```

[Open the upstream setup guide](https://github.com/lcy362/agnes-video-generator#readme) · [Try the hosted demo](https://video.lichuanyang.top)

> This repository links to the upstream app rather than copying or modifying its source. Configuration, dependencies, and API keys should be set up by following the upstream documentation.
